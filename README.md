Two-line explanation entry for make.fun's "Everyday Things, Two Lines, Longer Run" bounty, $2 winner-takes-all. The program writes two lines to `/output/entry.txt`: line 1 explains a toaster to a 10-year-old in one vivid sentence built on a sunbed analogy; line 2 says in one sentence why that analogy works — what it maps and what it leaves out.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
